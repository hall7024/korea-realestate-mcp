# korea-realestate-mcp v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> 실행 방식: 사용자가 외출 중이고 결정은 ai-oss-main·ai-oss-support에 위임됨. ai-oss-main이 설계 맥락을 모두 가지고 있으므로 inline(executing-plans)으로 실행하고, 주요 task 묶음마다 ai-oss-support에 리뷰를 요청한다.

**Goal:** 국토부 실거래가 13종을 조회하고 시세·전세가율을 계산하는 TypeScript 패키지(라이브러리 + CLI + stdio MCP 서버)를 만든다.

**Architecture:** `src/core`가 키·요청·파싱·정규화·지역·분석을 맡고, `src/mcp`와 `src/cli`는 core만 쓴다. 외부 의존(fetch, 캐시, 시계)은 주입받아 테스트에서 바꾼다. 설계: `docs/superpowers/specs/2026-11-11-v0.1-design.md`.

**Tech Stack:** Node ≥ 20, TypeScript 5 (ESM, NodeNext), pnpm 10, vitest 3, `@modelcontextprotocol/sdk` 1.32.2, `zod` 4.6.7, `fast-xml-parser` 5.12.0, ESLint 9 + typescript-eslint + eslint-plugin-security.

## Global Constraints

- 키는 환경변수 `DATA_GO_KR_SERVICE_KEY`만. 도구 입력·로그·오류·출력에 키와 요청 URL이 절대 나오지 않는다.
- 런타임 의존성은 sdk, zod, fast-xml-parser 3개만, 정확한 버전으로 고정.
- 요청: `https://apis.data.go.kr/1613000/{service}/get{service}`, `numOfRows=9999`, 타임아웃 15초, `redirect: "error"`, 동시 4건, 재시도 최대 3회(429·5xx·네트워크·code 23).
- 예산: 도구 호출 1회당 예상 API 호출 80건 초과 시 실행 거부.
- 날짜는 Asia/Seoul 기준.
- 금액은 원 단위 정수 + 표시 문자열을 함께.
- 판단 문구("위험", "적정") 금지. 숫자·표본·기준만.
- 로그는 stderr로만.
- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
