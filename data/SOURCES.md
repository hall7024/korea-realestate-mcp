# 데이터 출처

## regions.json

- 내용: 시도, 시군구(실거래가 API의 `LAWD_CD`), 법정동 이름, 옛 이름·옛 코드 → 새 코드 별칭
- 출처: 행정안전부 행정표준코드관리시스템(code.go.kr) "법정동코드 전체자료"
- 이용 조건: 공공누리 제1유형(출처표시). 출처: 행정안전부
- 만드는 법: `scripts/gen-regions.ts` 머리 주석
- 다시 만드는 때: 행정구역이 바뀔 때 (연 1회 이상 확인)

## 실거래가

이 패키지는 실거래가 자료를 담지 않는다. 사용자의 인증키로 국토교통부 실거래가 공개 API(공공데이터포털)를 직접 호출한다.
